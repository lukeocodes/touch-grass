# Privacy Policy — Touch Grass

**Last updated:** February 15, 2026

## Overview

Touch Grass is a browser extension that replaces GitHub contribution graphs with animated grass fields. It operates entirely within your browser and does not collect, store, transmit, or share any data of any kind.

## Data Collection

Touch Grass does **not** collect any data. This includes but is not limited to:

- Personal information
- Browsing history
- GitHub account or profile data
- Usage analytics or telemetry
- Cookies or local storage
- Crash reports

## Network Requests

Touch Grass makes **zero** network requests. It does not communicate with any server, API, or third-party service. All functionality runs locally in your browser using a single content script.

## Permissions

Touch Grass only requires access to `github.com` pages in order to find and replace the contribution graph with a canvas animation. It does not request any other browser permissions.

## Third-Party Services

Touch Grass does not integrate with, send data to, or receive data from any third-party services.

## Changes to This Policy

If this policy changes, the update will be reflected in this document with a revised date. Given the extension's scope, changes are unlikely.

## Contact

If you have questions about this privacy policy, open an issue at https://github.com/lukeocodes/touch-grass/issues.
